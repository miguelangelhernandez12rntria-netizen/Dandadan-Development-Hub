# Dandadan: Development Hub — Prototype 0.1

## Incluye
- Dashboard general.
- Registro de personajes, rareza, nivel y tipo.
- Historial manual de invocaciones y contador pity ilustrativo.
- Inventario de recursos.
- Misiones y eventos.
- Consola de desarrollo y notas.
- Exportación/importación de respaldos JSON.
- Diseño adaptable a móvil y escritorio.
- Manifest, icono y service worker para PWA.

## Probar
Abre `index.html` para una prueba local básica. Para instalar como PWA, publica todos los archivos en un hosting HTTPS y abre la dirección en el navegador del dispositivo. Usa "Añadir a pantalla de inicio" en iOS o "Instalar aplicación" en Android.

## Limitaciones de esta versión
- Los datos se guardan localmente en el navegador.
- No incluye cuentas, backend ni sincronización en la nube.
- El pity de 80 es ilustrativo y configurable; no representa reglas oficiales.
- No está afiliada oficialmente con Dandadan ni con otros videojuegos.
- Para publicar en tiendas se necesita empaquetado, pruebas, política de privacidad y cuentas de desarrollador.
